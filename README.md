# Dev Skill Workbench

This repository is intended for **practice, learning, and experimentation purposes only**.

It contains different projects and exercises that I use to practice various technologies, frameworks, libraries, and software development concepts.

## Purpose

The main purpose of this repository is to:

- Practice software development concepts
- Follow tutorials and crash courses
- Experiment with new technologies
- Improve coding skills
- Explore different project structures and approaches
- Add my own changes and improvements while learning

## Repository Structure

Different practice projects are stored in separate branches.

Examples:

- `laravel-react-crud-product-management` — Laravel + React practice project
- `nodejs-job-tracker-api` — Node.js API practice project
- `nextjs-authentication-ws02` — Next.js Authentication(WS02)(WIP)

Each branch may contain its own `README.md` with more information about the specific project.

## Learning Resources

Some projects in this repository may be based on:

- Tutorials
- Crash courses
- Official documentation
- Open-source repositories
- Coding exercises

When applicable, the original author, repository, course, or learning resource will be credited in the corresponding project's README.

## Personal Improvements

Although some projects may begin by following existing tutorials, I may also:

- Add new features
- Refactor existing code
- Improve validation
- Experiment with different approaches
- Change the project structure
- Apply concepts I have learned independently

These changes are part of my personal learning process.

## Disclaimer

The projects in this repository are created primarily for **educational and practice purposes**.

They should not necessarily be considered production-ready applications.

Some code may closely follow tutorials or other learning resources, while other parts may contain my own modifications and improvements.
